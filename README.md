# Portfolio

My personal portfolio, built as a small desktop you can poke around in. Open the apps to see my projects, experience, resume and notes.

Live at [rishikyesgari.com](https://rishikyesgari.com).

Built with Next.js, React, TypeScript and Tailwind CSS.

## Run it locally

```bash
npm install
npm run dev
```

Then open [localhost:3000](http://localhost:3000).
